Degradation Strategy

graceful (default)

Try Firebase AI Logic when enabled; on any failure fall back to the local engine with a visible badge.

local_only

Refuse cloud calls. An explicit cloud request returns a policy error; the local button still works.

offline

Refuse cloud calls and report the policy error. Local summaries remain available.

fail-loudly (none)

Surface cloud and App Check errors. Never silently replace a failed cloud request with a local result.
